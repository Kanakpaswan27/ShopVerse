## 📖 About

ShopVerse is a modern and fully responsive e-commerce website built to provide a premium online shopping experience.

The project focuses on creating a clean user interface, reusable React components, responsive layouts, and modern frontend development practices.

It is designed to simulate a real-world shopping platform with attractive product showcases, category browsing, featured collections, trending products, and premium user experience.

# 💻 Installation

Clone the repository

```bash
git clone https://github.com/Kanakpaswan27/ShopVerse.git
```

Go to project folder

```bash
cd ShopVerse
```

Install dependencies

```bash
npm install
```

Run the project

```bash
npm run dev
```
