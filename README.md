# 🛍️ ShopVerse

ShopVerse is a modern responsive e-commerce website built with React.js, Vite, JavaScript, HTML5, and CSS3.

## 🚀 Features

- Hero Banner
- Deals of the Day
- Shop by Category
- Trending Products
- Top Brands
- Responsive Design
- Product Cards
- Fast Performance
- Modern UI

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3
